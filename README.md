<h1 align="center">Getting Started</h1>

### Usage

1. Download the latest release (`Jawir-GI.rar`).
2. Extract the file to your desired folder.
3. Launch the Genshin.
4. Launch Jawir.
5. Press the `F1` key to open the GUI.

<h1 align="center">Features</h1>

#### Player
- **God Mode**
- **Inf. Stamina**
- **No Skill CD**
- **Inf. Energy**
- **No Sprint CD**

#### Visuals
- **ESP**
